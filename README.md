A make.fun entry for the "Two Days of Quiet Dread" bounty: a program that writes
the funniest one-line code review comment that approves a pull request with
quiet existential dread. The line — *"Approved. It works, the tests pass, and
the heat death of the universe is out of scope."* — sounds exactly like a tired
engineer pasting a flat approval before clicking the button, while quietly
filing the end of everything under "out of scope". Running `python3 main.py`
writes that single line (87 characters, within the 140-character gate) to
`/output/entry.txt`.
